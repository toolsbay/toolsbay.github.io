## 📖 Overview

**ToolsBay** is an ultra-minimalist, 100% client-side master web directory organizing over 60+ privacy-first, zero-server browser utilities. Powered by **Astro (SSG)** and **React Islands**, every tool operates entirely within the user's browser memory via WebAssembly, HTML5 Web APIs, and Canvas—requiring **zero accounts, zero subscriptions, and zero file uploads to remote servers**.

### 💡 Core Architectural Philosophy
- 🔒 **100% Zero-Server Privacy**: Your files, audio, video, photos, and spreadsheets never touch an external server or telemetry endpoint.
- ⚡ **Instant Client-Side Execution**: Pre-rendered static HTML with microsecond React hydration for instant fuzzy search and category switching.
- ⭐ **LocalStorage Favorites**: Persistent one-click bookmarking of daily tools without registration or databases.
- ⌨️ **Keyboard-First Workflow**: Seamless command palette search triggered with `Cmd/Ctrl + K` or `/`.
- 🌍 **Subpath Internationalization**: 7 pre-rendered locales (`/`, `/es/`, `/pt/`, `/de/`, `/fr/`, `/ja/`, `/zh/`) with reciprocal hreflang annotations.

## ⚡ Technical SEO Architecture

ToolsBay achieves a verified **100/100 Technical SEO rating**:

1. **Pre-Rendered Crawlable HTML**: All 65 tool cards render native `<a href="..." target="_blank" rel="noopener noreferrer">` in the initial server-generated HTML so Googlebot effortlessly indexes and passes PageRank authority across the network.
2. **Quad-Layer JSON-LD Structured Data**:
   - `WebSite` with `potentialAction` (`SearchAction`) for Sitelinks Search Box eligibility.
   - `Organization` declaring publisher ownership, logo, and founder credentials.
   - `BreadcrumbList` providing search result navigational trails (`ToolsBay › Free Browser Tools`).
   - `ItemList` detailing all 65 items as `SoftwareApplication` with `$0.00 USD` offers.
   - `FAQPage` answering privacy, client-side, and security queries for SERP accordion carousels.
3. **Automated XML Sitemaps**: Pre-rendered `sitemap-index.xml` and `sitemap-0.xml` featuring bidirectional `xhtml:link` hreflang cross-references across all 7 locales.
4. **Social Sharing**: Verified `1200×630` physical `og-image.png` with complete Open Graph and Twitter Card tags.
5. **Zero Cumulative Layout Shift (CLS = 0)**: Synchronous anti-FOUC theme script runs in `<head>` before DOM render.

## 🚀 Quick Start

### Prerequisites
- **Node.js**: v18.0.0 or later (v24+ recommended)
- **npm**: v9.0.0 or later

### Installation & Local Development

```bash
# 1. Clone the repository
git clone https://github.com/toolsbay/toolsbay.github.io.git
cd toolsbay.github.io

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:4321` in your browser.

### Production Build & Verification

```bash
# Compile static site with sitemaps and localized pages
npm run build

# Preview production build locally
npm run preview
```
